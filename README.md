## BlablaBills

How much is this meeting really costing you?
BlablaBills makes the hidden cost of endless discussions obvious.

Watch the bill climb — and what you could’ve bought instead.

www.blablabills.com

### Features
Add participants, set an hourly wage, pick a currency, and start
the clock.


### Ideas
- Make results shareable via link
- Integrate API for actual products
- Live Edits: remove participants, change hourly wage, etc. while the clock is running
- Leaderboard for most expensive meetings
- User login to save past meetings, create meeting configs for re-occurring meetings etc.
